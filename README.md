# Код к курсу «Нейросети для работы»

В репозитории собраны учебные Jupyter Notebooks для демонстраций на вебинарах и самостоятельной практики. Презентаций, конспектов и тестов здесь нет.

## Что понадобится

- Python 3.10 или новее;
- JupyterLab или Jupyter Notebook;
- Ollama и модель `qwen2.5:3b` — только для примеров с локальной языковой моделью.

Платные API и ключи для запуска notebooks не требуются. Все примеры, кроме обращения к Ollama, используют стандартную библиотеку Python.

## Как скачать

Для простого варианта нажмите **Code → Download ZIP**, распакуйте архив и откройте полученную папку.

Если вы умеете работать с Git:

```bash
git clone https://github.com/SemVan/course-code.git
cd course-code
```

## Как запустить

1. Откройте Anaconda Navigator.
2. Запустите JupyterLab.
3. В JupyterLab откройте папку репозитория.
4. Перейдите в папку `notebooks` и откройте нужный файл.
5. Выполняйте ячейки по порядку командой **Shift+Enter**.

Для notebook с локальной моделью сначала установите Ollama и загрузите модель:

```bash
ollama pull qwen2.5:3b
```

## Состав

1. `01_llm_evaluation.ipynb` — оценка ответов LLM по критериям.
2. `02_ollama_local_llm.ipynb` — обращение к локальной модели через Ollama.
3. `03_reliable_http_client.ipynb` — обработка сетевых ошибок и повторные запросы.
4. `04_json_validation.ipynb` — безопасный разбор и проверка JSON.
5. `05_sqlite_memory.ipynb` — хранение истории диалога в SQLite.
6. `06_minimal_rag_tfidf.ipynb` — простой локальный поиск по базе знаний.
7. `07_telegram_update_simulator.ipynb` — структура сообщений Telegram без настоящего токена.
8. `08_workflow_retry.ipynb` — повторное выполнение шагов и защита от дублей.
9. `09_bounded_agent.ipynb` — агент с ограниченным набором состояний и действий.

## Важно

Не добавляйте в notebooks пароли, токены Telegram, API-ключи, персональные данные и рабочие документы. Перед публикацией очищайте результаты выполнения ячеек.
